*********************************
`Десктопное развертывание`:index:
*********************************

pgAdmin можно развернуть как десктопное приложение, настроив его работу в соответствующем 
режиме и используя среду выполнения для десктопных систем для запуска программы в поддерживаемых 
операционных системах Windows, Mac OS X или Linux.

Десктопная среда выполнения - это автономное приложение, которое при запуске инициализирует 
сервер pgAdmin и открывает окно для отображения пользовательского интерфейса.

.. note:: Предварительно скомпилированные и настроенные установочные пакеты доступны
     для большинства платформ. Конечным пользователям следует использовать эти пакеты, 
     приведенная ниже информация будет полезна их сопровождающим, а также пользователям, 
     желающим понять принципы работы pgAdmin.

.. seealso:: Для более подробных инструкций по сборке и настройке pgAdmin с нуля
    см. файл README в корневом каталоге исходного кода.
    Для удобства вы можете найти последнюю версию файла
    `здесь <https://github.com/Vermillion-Develop/pgadmin4_ru/blob/master/README_RU.md>`_,
    однако имейте ввиду, что она может отличаться от версии, входящей в состав 
    исходного кода для конкретной версии pgAdmin.

Конфигурация
************

Начиная с версии pgAdmin 4 v2, режимом конфигурации по умолчанию является сервер, однако 
при запуске этот параметр переопределяется средой выполнения для десктопных систем. 
В большинстве случаем дополнительная настройка Python не требуется, если только вы не хотите 
изменить другие параметры, установленные по умолчанию.

См. :ref:`config_py` для получения дополнительной информации о параметрах конфигурации.

Автономное десктопное приложение
================================

Среда выполнения для десктопных компьютеров основана на `Electron <https://www.electronjs.org/>`_, который 
объединяет браузер и сервер на Python, создавая автономное приложение.

.. image:: images/runtime_standalone.png
    :alt: Автономная среда выполнения
    :align: center

Элементы меню, доступные во время выполнения
--------------------------------------------

.. image:: images/runtime_menu.png
    :alt: Меню среды выполнения
    :align: center

Используйте меню *Файл* для доступа к пунктам меню, доступным во время выполнения программы:

+-------------------------+------------------------------------------------------------------------------------------------------------+
| Пункт                   | Действие                                                                                                   |
+=========================+============================================================================================================+
| *View Logs...*          | Нажмите, чтобы открыть диалоговое окно просмотра логов и просмотреть логи pgAdmin 4.                       |
+-------------------------+------------------------------------------------------------------------------------------------------------+
| *Configure runtime...*  | Нажмите, чтобы открыть диалоговое окно настройки фиксированного порта, номера порта и тайм-аута соединения.|
+-------------------------+------------------------------------------------------------------------------------------------------------+

Диалоговое окно настроек
------------------------

Используйте пункт *Configure runtime...* (Настройка среды выполнения) для доступа к окну *Configuration* (Конфигурация):

.. image:: images/runtime_configuration.png
    :alt: Runtime Configuration
    :align: center

Ниже приведены подробные сведения о параметрах конфигурации *FixedPort* (Фиксированный порт), *PortNumber* (Номер порта), 
*ConnectionTimeout* (Тайм-аут соединения), и 'Open Documentation in Default Browser' (Открыть в браузере по умолчанию) configuration parameters:

.. table::
   :class: longtable
   :widths: 2 1 4

   +----------------------------------------+--------------------+-------------------------------------------------------------------+
   | Параметр                               | Тип                | Цель                                                              |
   +========================================+====================+===================================================================+
   | FixedPort                              | Boolean            | Использовать фиксированный номер сетевого порта вместо случайного.|
   +----------------------------------------+--------------------+-------------------------------------------------------------------+
   | PortNumber                             | Integer            | Номер используемого порта (если включен фиксированный порт).      |
   +----------------------------------------+--------------------+-------------------------------------------------------------------+
   | ConnectionTimeout                      | Integer            | Количество секунд ожидания запуска сервера приложений.            |
   +----------------------------------------+--------------------+-------------------------------------------------------------------+
   | Open Documentation in Default Browser  | Boolean            | Если этот флаг включен, все ссылки на документацию будут          |
   |                                        |                    | открываться в браузере по умолчанию, а не в новом окне.           | 
   +----------------------------------------+--------------------+-------------------------------------------------------------------+

Окно логов
----------

Используйте пункт *File Menu* (Меню "Файл") для доступа к окну *View Logs* (Просмотр логов):

.. image:: images/runtime_view_log.png
    :alt: Runtime View Log
    :align: center

Нажмите кнопку *Reload* (Обновить) в нижней части, чтобы просмотреть последние 
логи сервера pgAdmin4.

При запуске среда выполнения автоматически попытается запустить Python-приложение 
pgAdmin. В случае сбоя появится сообщение об ошибке с кнопкой *Configure* (Настроить) 
в нижней части окна. При необходимости можно задать фиксированный номер порта, чтобы 
избежать конфликтов случайно выбранного порта по умолчанию с другими приложениями, а 
также настроить тайм-аут соединения.

.. image:: images/runtime_error.png
    :alt: Runtime Error
    :align: center

Если ошибка связана с путем к Python или файлов Python для pgAdmin, то неободимо
создать файл с именем 'dev_config.json' и указать в нем следующие параметры:

.. code-block:: json

    {
        "pythonPath": "/path/to/python.exe",
        "pgadminFile": "/path/to/pgAdmin4.py"
    }

Обратите внимание, что файл *dev_config.py* может понадобиться только тем разработчикам, 
которые работают вне стандартной установки.

Параметры конфигурации находятся в файле *runtime_config.json*, 
который будет доступен в системах Linux (~/.local/share/pgadmin/),
на Mac OS X (~/Library/Preferences/pgadmin),
и на Windows (%APPDATA%/pgadmin).
