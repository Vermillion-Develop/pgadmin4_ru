**********************
`Начало работы`:index:
**********************

Для ряда десктопных сред доступны предварительно собранные и настроенные установочные 
пакеты pgAdmin4, по возможности мы рекомендуем использовать установщик.

При *развертывании сервера*, приложение pgAdmin размещается за веб-сервером
или работает через интерфейс WSGI.

При установке pgAdmin в серверном режиме во время первого подключения к приложения
 потребуется указать имя роли и пароль. Первая роль, зарегистрированная в pgAdmin, 
 будет обладать правами администратора; администратор может использовать диалоговое 
 окно *User Management* (Управление пользователями) для создания дополнительных 
 учетных записей и управления ими. После аутентификации пользователя в дереве 
 объектов pgAdmin отображаются определения серверов, связанные с данной учетной 
 записи.

В рамках *десктопного развертывания*, приложение pgAdmin настроено на 
использование среды выполнения для десктопных систем для запуска программы 
на поддерживаемой платформе.

Обычно для запуска pgAdmin в режиме десктопного приложения пользователи 
устанавливают готовый пакет, однако возможна и ручная установка, хотя такой 
способ сложнее в настройке, он может быть полезен разработчикам, желающим 
понять принципы работы pgAdmin.

Также можно развернуть pgAdmin в виде *контейнера*, где серверный режим 
предварительно настроен с учетом требований безопасности.

.. note:: Скомпилированные и настроенные установочные пакеты доступны 
   для большинства платформ. Конечным пользователям следует по возможности использовать 
   эти пакеты, приведенная ниже информация будет полезна их сопровождающим, а также 
   пользователям, желающим понять принципы работы pgAdmin.

Клиент pgAdmin 4 отличается широкими возможностями настройки интерфейса: панели можно 
перемещать методом перетаскивание (drag-and-drop ) и распологать так, чтобы максимально 
эффективно использовать рабочее пространство.

Элемент управления в виде дерева обеспечивает наглядное представление управляемых серверов и 
объектов, размещенных на каждом из них. Нажатие правой кнопки мыши по узлу дерева открывает 
контекстное меню, предоставляющее быстрый доступ к задачам управления для выбранного объекта.

Браузер с вкладками обеспечивает быстрый доступ  к статистической информации о каждом объекте в 
дереве навигации, а также к инструментам и утилитам pgAdmin (таким как редактор запросов и отладчик). 
pgAdmin открывает дополнительные вкладки при каждом обращении к расширенным возможностям инструментов 
программы, вы можете открывать, закрывать, и переупорядочивать эти вкладки по мере необходимости.

Используйте окно *Preferences* (Настройки) для настройки содержимого и поведения pgAdmin. 
Чтобы открыть окно *Preferences*, выберите пункт *Настройки* из меню *File* (Файл).

Кнопки *Help* (Справка) в левом нижнем углу каждого диалогового окна открывают справочную информацию, 
относяюуюся к данному окну. Дополнительную справку по Postgres можно получить, перейдя в меню *Help* 
и выбрав нужный ресурс.
