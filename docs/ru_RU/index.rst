*********
pgAdmin 4
*********

.. image:: images/logo-right-128.png
    :align: right
    :alt: pgAdmin Logo

Добро пожаловать в pgAdmin 4. pgAdmin это ведущий инструмент управления Postgres с открытым исходным кодом, 
самой совершенной в мире базы данных с открытым исходным кодом. pgAdmin 4 разработан для удовлетворения потребностей 
как начинающих, так и опытных пользователей Postgres; он предоставляет мощный графический интерфейс, упрощающий создание, 
обслуживание и использование объектов базы данных.
