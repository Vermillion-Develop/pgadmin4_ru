***************************
`Файл конфигурации config.py`:index:
***************************

При запуске pgAdmin считывается несколько конфигурационных файлов. Эти 
файлы используются для параметров конфигурации, которые:

* возможно, потребуется задать перед запуском pgAdmin, 
  так как они определяют порядок работы приложения;
* системные администраторы могут захотеть осуществлять цетрализованный контроль 
  в масштабах всей организации для обеспечения соблюдения политик безопасности;
* изменяются настолько редко или маловероятно, что нет смысла разрешать 
  их изменение через пользовательский интерфейс.

Файлы конфигурации выглядят следующим образом:

* ``config.py``: Это основной файл конфигурации, который не должен как-либо изменяться.
  Его можно использовать в качестве справочника настроек конфигурации, 
  которые могут быть переопределны в одном из следующих файлов.

* ``config_distro.py``: Этот файл считывается после ``config.py`` и предназначен для того, 
  чтобы специалисты, занимающиеся сборкой пакетов, могли изменить настройки, необходимые 
  для их дистрибутива pgAdmin. Обычно это касается определенных путей и расположения файлов. 
  Данный файл не является обязательным, при необходимости сборщики могут создать его в том же 
  каталоге, гд находится файл ``config.py`` если это потребуется.

* ``config_local.py``: Этот файл считывается после ``config_distro.py`` и предназначен
  для того, чтобы владелец установки изменить любые стандартные или специфические настройки,
  для дистрибутива в соответствии с локальными предпочтениями или стандартами. 
  Этот файл является необязательным, и при необходимости пользователи могут создать его 
  в том же каталоге, где находится ``config.py``.

* ``config_system.py``: Этот файл считывается после ``config_local.py`` и предназначен 
  для системных администраторов, чтобы они могли задавать общие системные настройки, 
  хранящиеся в защищенном месте вне каталога установки pgAdmin, недоступном для обычного 
  изменения пользователями. Расположение этого файла зависит от платформы, создавать его 
  нужно только при необходимости.

  .. csv-table::
     :header: "**Платформа**", "**Расположение файла**"

     Linux,/etc/pgadmin/config_system.py
     macOS,/Library/Preferences/pgadmin/config_system.py
     Windows,%CommonProgramFiles%\\pgadmin\\config_system.py

.. note:: Если настройки SERVER_MODE или DATA_DIR были изменены в
     ``config_distro.py``, ``config_local.py``, or ``config_system.py``
     LOG_FILE, SQLITE_PATH, SESSION_DB_PATH, STORAGE_DIR, KERBEROS_CCACHE_DIR,
     и AZURE_CREDENTIAL_CACHE_DIR значения будут установлены на основе DATA_DIR за 
     исключением случаев, когда значения для какой-либо из переменных в любом из 
     вышеуказанных файлов переопределены явно.
